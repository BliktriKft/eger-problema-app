MANUAL BOOTSTRAP — STEP BY STEP
-------------------------------

The fastest path right now (no PAT swap needed if you have any write-scoped
PAT or if you're OK doing one round of UI work):

  1. Open https://www.figma.com/files/team/BliktriKft
     (or https://www.figma.com/files/recent if not in a team context)

  2. Click "New design file" → name it:
         Eger Város Probléma Térkép — Design System

  3. The new file's URL will look like:
         https://www.figma.com/file/<FILE_KEY>/Eger-Város-...
     Copy the <FILE_KEY> segment.

  4. Add to ~/.hermes/profiles/website-designer/.env:
         FIGMA_FILE_KEY=<paste the key here>

  5. Run the bootstrap:
         cd /home/bliktri/workspaces/eger-problema-app
         pnpm --filter @eger/design figma:export --dry-run    # preview
         pnpm --filter @eger/design figma:export              # actually create

     The script will create 7 pages (idempotent — already-existing pages are
     skipped) and rewrite this file with the live URL.

  6. Open the resulting Figma file URL and drag in the component frames
     described in design/figma-spec.md. The script only scaffolds pages, not
     visual content.


IF YOU NEED A WRITE-SCOPED PAT
------------------------------

  1. Go to https://www.figma.com/developers/api#access-tokens
  2. "Create a new personal access token"
  3. Name it "eger-problema-design-bootstrap"
  4. Set scope to **File content (read+write)**
     — Without this, /v1/files/<key>/pages returns 403.
  5. Make sure the token has visibility into the BliktriKft team:
     - If BliktriKft is a Figma team you're a member of, the PAT can see it.
     - If BliktriKft is just a workspace folder under your personal account,
       the PAT can still see it (workspaces are per-user).
     - Either way, the token must be created by a Figma account that is a
       member of BliktriKft (or by the team admin) — Personal Access Tokens
       only see files the user can already see.
  6. Paste the new token into ~/.hermes/profiles/website-designer/.env,
     replacing the old FIGMA_PERSONAL_ACCESS_TOKEN line.
