HOW TO BOOTSTRAP

Once a token with file-write scope is available, do the following:

1. Get a Personal Access Token from Figma → Settings → Personal access tokens.
   Required scopes: File content (read + write).

2. Add it to ~/.hermes/profiles/website-designer/.env:
       FIGMA_PERSONAL_ACCESS_TOKEN=figd_xxxxxxxxxxxxxxxxxxxxxxxxxxxxx
       FIGMA_FILE_KEY=        # leave empty until file is created

3. From /home/bliktri/workspaces/eger-problema-app:
       pnpm --filter @eger/design figma:export

   The bootstrap script will:
   - POST to https://api.figma.com/v1/files (or use the team endpoint
     https://api.figma.com/v1/teams/<TEAM_ID>/files) to create a new file
     in the BliktriKft workspace.
   - Capture the file key from the response and write it to FIGMA_FILE_KEY.
   - Create the 13 required pages (Cover, Tokens, Components, 7 Web screens,
     4 Mobile screens, Accessibility audit, Empty/Loading/Error states).
   - Save the public file URL to design/figma-url.txt.

4. Re-run the export script to sync design tokens to the Figma variables panel:
       pnpm --filter @eger/design figma:export
